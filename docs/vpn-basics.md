# VPN 基础知识完全指南

## 什么是 VPN？

VPN（Virtual Private Network，虚拟专用网络）是一种通过公共网络建立加密隧道的技术。它可以：

- **加密你的网络流量**：防止 ISP、政府或黑客窃听
- **隐藏真实 IP 地址**：保护隐私和匿名性
- **突破地理限制**：访问不同地区的内容
- **安全访问公共 WiFi**：避免中间人攻击

## VPN 工作原理

### 1. 建立加密隧道

当你连接到 VPN 服务器时，客户端会：

1. 与 VPN 服务器协商加密参数
2. 建立加密隧道（Tunnel）
3. 所有流量通过这个隧道传输
4. 服务器解密后转发到目标网站

### 2. 数据传输流程

```
你的设备 → 加密 → VPN 服务器 → 解密 → 目标网站
         ← 加密 ← VPN 服务器 ← 加密 ← 目标网站
```

### 3. IP 地址替换

外部网站看到的是 VPN 服务器的 IP，而不是你的真实 IP。

## VPN 的主要用途

### 1. 隐私保护

- 防止 ISP 记录你的浏览历史
- 避免广告商追踪
- 保护敏感数据传输

### 2. 安全连接

- 公共 WiFi 加密保护
- 防止 DNS 劫持
- 避免中间人攻击

### 3. 访问受限内容

- 访问被屏蔽的网站和服务

## VPN 类型对比

### 远程访问 VPN

个人用户最常用的类型：

**优点**：
- 配置简单
- 适合个人使用
- 成本较低

**缺点**：
- 速度取决于服务商
- 可能有日志记录
- 需要信任服务提供商

### 站点到站点 VPN

企业级应用：

**优点**：
- 连接多个办公地点
- 集中管理
- 高度安全

**缺点**：
- 配置复杂
- 成本较高
- 需要专业维护

## 如何选择 VPN 服务

**速度**：

## 安全性最佳实践

### 1. 选择强加密

- 使用 AES-256 加密
- 启用完美前向保密（PFS）
- 定期更新客户端

### 2. DNS 泄露防护

- 使用 VPN 提供的 DNS
- 启用 DNS 泄露保护
- 定期测试泄露情况

### 3. Kill Switch

- 启用自动断网保护
- 防止 VPN 断线时暴露真实 IP
- 特别重要的隐私保护功能

### 4. 多因素认证

- 启用账号二次验证
- 使用强密码
- 定期更换凭证

## 常见问题解答

### Q1: VPN 会降低网速吗？

会有一定影响，因为：
- 加密/解密需要时间
- 数据需要中转
- 服务器距离影响延迟

但好的服务商速度损失可控，通常在 10-30%。

### Q2: VPN 是否完全匿名？

不完全。VPN 可以：
- ✅ 隐藏你的 IP 地址
- ✅ 加密你的流量
- ❌ 无法隐藏你的登录账号
- ❌ 无法防止浏览器指纹追踪

### Q3: 免费 VPN 安全吗？

大多数免费 VPN 有以下问题：
- 🚫 可能记录并出售你的数据
- 🚫 速度和带宽严重限制
- 🚫 安全性无法保证
- 🚫 可能注入广告

建议使用信誉良好的付费服务。

### Q4: 可以在手机上使用 VPN 吗？

可以，主流系统都支持：
- iOS: Shadowrocket、Quantumult X
- Android: Clash、V2RayNG
- 配置方法见：[客户端配置指南](./client-setup.md)

### Q5: VPN 会被检测和封锁吗？

部分地区会检测和封锁 VPN：
- 使用混淆技术可以提高成功率
- 选择支持高级协议的服务
- 定期更新服务器信息

更多技术细节见：[安全性最佳实践](./security-best-practices.md)
