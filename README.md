## 📖 VPN 基础知识

VPN（Virtual Private Network，虚拟专用网络）是一种通过公共网络建立加密连接的技术，可以：

- 保护网络隐私和数据安全
- 突破地理位置限制
- 避免 ISP 流量监控
- 访问受限制的内容

## ❓ 常见问题

### 1. 如何选择合适的协议？

根据你的使用场景：
- **日常浏览**：Shadowsocks 即可满足
- **高强度需求**：推荐 V2Ray 或 Trojan
- **追求速度**：WireGuard 是最佳选择

### 2. 自建服务器 vs 购买服务？

- **自建优势**：完全掌控，隐私性更好
- **购买优势**：维护简单，多节点选择

详细分析：[自建 vs 购买全面对比](./docs/self-hosted-vs-services.md)

### 3. 如何提升连接速度？

- 选择物理距离近的节点
- 使用 TCP 加速技术（BBR/锐速）
- 优化 MTU 设置
- 选择负载较低的时段

更多优化技巧：[网络加速优化指南](./docs/speed-optimization.md)
